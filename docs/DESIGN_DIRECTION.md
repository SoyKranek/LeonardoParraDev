# Dirección creativa — Leonardo Parra Dev v2

## Dirección principal: Glass Futurista
- Fondo oscuro profundo con capas de gradiente azul/cian/violeta.
- Superficies glass (`backdrop-blur`, bordes sutiles, transparencias).
- Tipografía: Inter (UI) + JetBrains Mono (detalles técnicos).
- Sensación: ingeniero moderno, confiable, premium.

## Dirección secundaria: Cinematic Tech
- Entradas secuenciales con Framer Motion.
- Hero con escena 3D abstracta (partículas + icosaedro wireframe).
- Microinteracciones en cards, CTAs y navegación sticky.
- Scroll progress + reveal por secciones.

## Principios UX
1. Legibilidad primero (contraste AA).
2. 3D solo en hero; fallback 2D en móvil.
3. Performance: lazy load de Three.js.
4. Contenido editable vía repository pattern.
